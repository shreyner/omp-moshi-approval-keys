# Работа в omp-moshi-approval-keys

- Расширение — обход бага moshi-hook: на approval-диалог omp он отвечает буквой `y`/`n`, а не
  клавишами диалога. Логика целиком в `src/index.ts`, описание и ограничения — в `README.md`.
- Проверки: `bun run test` и `bun run check` (tsc + biome). Последний тест гоняет approval-диалог
  установленного omp из `~/.bun/install/global` и пропускается, если omp не установлен (так в CI):
  после обновления omp прогоняй тесты, он упадёт, если диалог сменил клавиши.
- Репозиторий публичный: без абсолютных путей пользователя, внутренних адресов и рабочих данных.
- Не устанавливай новые зависимости и не меняй `~/.omp/agent/config.yml` автоматически.
- Коммиты — с личной SSH-подписью из локального git-конфига, без `Co-Authored-By`. Не коммить,
  не пушь и не публикуй без просьбы.
